# 枪火风暴3D · Godot 工程版

真正的 3D 引擎项目，为长期升级设计：脚本/场景/资源分文件管理，以后加枪、Boss、地图都是加文件。

## 手机上跑起来（3 步）

1. **装 Godot 编辑器**：Google Play 搜「Godot Engine」（或官网下 APK），要求 4.3 以上版本
2. **导入项目**：把整个 `godot-gun` 文件夹放到手机存储（记住路径），打开 Godot → Import → 选中文件夹里的 `project.godot` → Import & Edit
3. **运行**：点右上角 ▶ 播放按钮，横屏游玩

> 首次打开会自动导入资源（会生成 .godot 缓存文件夹），属正常现象。

## 操作

| 触控 | 功能 |
|---|---|
| 左半屏按住拖动 | 虚拟摇杆移动 |
| 右半屏滑动 | 转视角 |
| 开火（按住） | 自动连发；**开火键上滑动可直接转视角**（双指同时操作） |
| 镜 | 开镜/收镜（视野收窄、散布减小） |
| 跳 / 弹 | 跳跃 / 换弹 |
| 左上角 ⚙ | 设置：陀螺仪瞄准开关、灵敏度调节（自动存档） |

## 工程结构（升级就在这里加东西）

```
godot-gun/
├── project.godot        引擎配置（横屏、移动渲染器、触控）
├── main.tscn            主场景（入口）
├── fonts/ui.otf         中文 UI 字体（按需子集，25KB）
└── scripts/
    ├── main.gd          世界搭建、波次管理、触屏输入、HUD
    ├── player.gd        玩家：移动/射击/换弹/开镜/后坐力
    └── enemy.gd         敌人：追击 AI/攻击/死亡动画
```

## 后续升级路线（每个都是加文件的事）

- 🔊 音效：导入 wav/ogg，在 player.gd 射击处 `AudioStreamPlayer.play()`
- 🔫 多武器：复制 player.gd 的 shoot() 改弹道参数（霰弹=多射线、狙击=高伤低射速）
- 👹 Boss：复制 enemy.gd 调大参数 + 新技能脚本
- 🗺️ 新地图：main.gd 的 build_map() 里加方块，或做成独立 .tscn 切换
- 🎁 更多道具：照 medkits 的写法加弹药箱/护甲
- 📦 导出 APK：需要一次电脑（装导出模板），之后就能发给别人装
